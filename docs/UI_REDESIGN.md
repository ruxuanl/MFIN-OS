# MFIN OS UI 改版（2026-11-14）

依据：用户明确批准当前会话中的完整改版计划；沿用 PRODUCT_SPEC.md 的单用户、双端、三个独立领域及权限边界。

## 视觉与交互

- Linear 导航与层级、Attio 表格与详情；白灰底色、蓝色操作入口，浅深色跟随系统。
- Apple 使用系统字体及苹方；Windows 使用自托管 Inter / Noto Sans SC。WOFF2 按 unicode-range 分片，保留字体许可证，加载失败使用系统回退；构建不依赖外部字体服务。
- 移除衬线标题与局部字号加成。页面标题 28px，分区标题约 18px，正文 14–15px，辅助信息 12–13px。手机输入 16px、主要触控区域至少 44px。
- 首页突出三个行动、日程和来源健康；实习与秋招默认展示追踪表，候选池单独切换，JD 导入使用弹窗。
- 表格默认五个核心列，其余已有列按需显示；手机呈现字段列表。
- 桌面列表内导航使用 Next.js parallel / intercepted routes 打开详情抽屉；直接访问或刷新详情为完整页面。概览、材料与申请、沟通、历史四组保留现有表单与服务端权限。
- 核心字段默认阅读态；更多属性、编辑表单按需展开。冲突始终在页签上方展示。
- 原生 dialog 提供焦点约束、Escape 与关闭后焦点恢复。未保存提示覆盖关闭、链接、刷新和浏览器历史；旧 History API 使用同地址保护项。
- 客户端编辑保留原 RPC、版本、离线队列与字段锁，增加同步提交防重与网络异常反馈。
- PWA 图标与主题色同步更新，shell cache 升级为 v3。

- 临时注入 32 条合成岗位，仅作用于 AUTH_MODE=mock 预览；验证五个默认列、额外列、详情页签、抽屉保留列表／筛选／滚动、前进重开、刷新完整详情、未保存关闭与返回提示。
- 分别验证 Navigation API 与禁用该 API 后的旧 History API 路径。
- CDP 确认中文标题由自托管 Noto Sans SC 渲染；模拟字体请求失败后页面仍可读。
- 移动详情全屏，无内部横向溢出；减少动态效果模式已检查。

- 合成 getter 临时修改在 CI 前已逐字节恢复，未修改实际数据查询或数据库，没有真实业务写入。
