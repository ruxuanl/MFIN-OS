# 本地日历与行动排期

2026-11-15：用户明确授权先在 localhost 改版，并连接本人 Google Calendar；不发布云端。

入口：<http://localhost:3000/calendar>，使用 design-pr 原有真实 Test 连接，不切换 mock 或其他数据库。

- 页面仅有 Calendar 和行动排期同步两个主区域。Calendar 默认月历，选择日期查看当日安排；支持切换月份和回到今天。
- 已连接时，页面从 Google Calendar 读取当前六周网格的实际事件，展开重复事件，使用 Asia/Hong_Kong。查看页面不会处理待写入队列或创建日历；读取失败明确显示缓存警告。
- 连接、暂停、重新验证、断开与权限管理收进“连接设置”。读取和每次 Google 请求继续检查隐私锁、连接和权限。
- 候选池包含未完成、未取消、尚未成功同步的行动；成功同步的行动可展开查看和编辑。个人行动可在本页编辑，其他行动保持原所属工作区的修改路径。
- “确认同步时间事件 / 全天事件”先通过现有 queue_action_calendar_sync 登记，再立即运行原同步服务。稳定事件 ID、版本、只写产品日历、冲突处理与审计保持原实现。
- 新建支持“仅保存到候选池”和“创建并确认同步”。datetime-local 按香港时间解析。同步失败时保留已创建行动和队列，用户从候选池重试，不必再新建。
- 待处理和失败写入都阻止显示全部同步成功；权限关闭时保留待同步，不绕过限制。

验证：55 项 calendar 单元/流程测试、类型及定向 ESLint；真实 Google 只读查询返回 34 项，无测试事件写入。合成数据浏览器验证浅色/深色月历、日期选择、月份导航及默认收起连接设置，无页面错误或横向溢出。截图在忽略目录 work/design/calendar-light.png、calendar-dark.png。


## 2026-11-15 日程放大与优先级

点击任意日期打开当天详情，可滚动查看完整标题、时间、来源、地点和原日历入口；原生对话框支持 Escape、关闭按钮、点击遮罩关闭及焦点返回。月历预览、侧栏和放大详情都采用同一绿色优先级色阶（低、普通、高、关键）。通过产品行动标记关联现有行动优先级，普通Google日程无优先级时标注“未标记”并使用浅绿虚线框，不猜测重要程度。

本次验证：56项calendar测试通过，类型检查和定向ESLint通过，设计扫描[]。合成数据浅色/深色浏览器验证五种样式、长标题完整显示、空日期、键盘打开/Escape关闭/焦点返回、关闭按钮/遮罩，无页面错误或横向溢出。截图work/design/calendar-expanded-light.png、calendar-expanded-dark.png及calendar-priority-light.png。未调用Google写入，仍只在本地3000生效。
