# 测试策略

## M0 基线

`pnpm run ci` 必须依次执行：

1. UTF-8 与文件结尾检查。
2. 治理文件、决策记录、密钥文件和第二阶段目录边界检查。
3. Node.js 脚本语法检查。
4. 基于 `node:test` 的产品边界回归测试。

M0 不安装产品依赖，不运行数据库，不连接外部账号。GitHub Actions 工作流仅代表配置已建立；在没有远程仓库时，远程执行状态为“未确认”。

## 后续测试层级

- 单元：领域状态机、权限组合、字段锁、评分解释和报告排序。
- 契约：OpenAPI、适配器接口和后台任务事件。
- 集成：数据库事务、Outbox、队列、对象存储和搜索。
- Web/PWA E2E：电脑与 iPhone 布局、离线、冲突、Passkey、通知和快捷导入。
- 隐私：日志脱敏、权限关闭、隐私锁、数据最小化和永久删除。
- 恢复：单对象、工作区和全系统恢复，以及删除墓碑传播。
- 失败注入：令牌过期、限流、断网、重复任务、部分完成和来源失效。

## 数据规则

- 默认只用合成数据。
- 真实 Google 联调使用专门测试账户和测试日历。
- 任何真实数据测试都需要对应里程碑授权、最小范围和明确删除路径。

## 验收记录

每个里程碑结束时记录：运行命令、环境、结果、未确认项、真实设备/外部服务缺口和回归风险。未经用户确认，不自动进入下一里程碑。

## M2 验收

- `pnpm run ci`：格式、治理、ESLint、TypeScript、静态检查、根测试、Web 测试和 Next.js 生产构建。
- 迁移回归：公开表 RLS、显式 Data API 授权、永久禁止能力和数据库安全触发器静态检查。
- 隔离 Supabase 事务测试：AI 总开关、隐私锁、任务取消、重新验证门、一次性授权消费、重试上限、dead-letter 和敏感载荷拒绝；事务结束回滚。
- Security/Performance Advisor：修复公开 RLS、重复策略和缺失外键索引；空表的 unused-index 信息属于预期基线。
- 测试后确认权限、隐私锁、任务和审计业务表均无合成记录残留。

## M3 验收

- `pnpm run ci`：M3 迁移静态约束、工作区领域单元测试、ESLint、TypeScript 和 Next.js 生产构建。
- 隔离 Supabase 回滚事务：候选 promotion、实习/秋招轨道不可变、不同字段并发自动合并、同字段显式冲突、人工解决、字段锁、隐私锁拒绝写入和 Action 循环依赖拒绝。
- 幂等与离线：同一 mutation ID 不重复执行；Outbox 只在服务器确认后出队；失败保留可重试状态；冲突进入人工解决队列。
- 响应式视觉：桌面与 iPhone 宽度验证筛选、卡片、详情、底部导航和无横向溢出；离线页只展示最小快照。
- Advisor：公开表无 RLS/函数暴露、重叠 permissive policy 或缺失外键索引告警；空表 unused-index INFO 属预期基线。
- 所有合成事务结束回滚，并复核 M3 业务表无测试残留。

- 隐私测试必须证明非白名单窗口不采集、无关消息不上云、临时截图到期删除、日志无完整聊天/成员信息，并可一键停止。
