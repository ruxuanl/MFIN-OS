# ADR-0007：M7 微信雷达以本地净化投影和停止代数为边界

- 状态：已接受，M7 实施中
- 日期：2026-08-13
- 依据：用户批准 M7；`docs/DECISIONS.md` D20 与 M7 里程碑授权

## 决定

Windows 监测器只处理微信桌面端可见界面，并在本地完成白名单身份核验、OCR、JD 判断和隐私净化。它不能直写候选池或收件箱，只能调用 service-only 的最小投影入口。

数据库入口在单一事务中重新检查 `wechat.monitor` 及依赖授权、稳定群身份指纹、运行健康、新鲜心跳与 stop generation。总停止会递增 stop generation，使停止前已经在途的旧请求失效。capture key 提供幂等；高置信规则投影进入候选池，低置信进入待确认，任何结果都不自动进入长期表。

本地执行器以独立 Node 进程、合成适配器和 `visible_ocr_v1` 真实适配器落地。它在扫描前、逐群和每个写入点拉取 service-only 任务分配并核对停止代数，再上报服务器时间心跳。真实适配器固定为 Windows Media OCR：当前群无需交互；切换白名单群只允许用户空闲且微信前台时点击左侧可见群行，每 90 秒最多一次，不滚动、不使用键盘/剪贴板，也没有发送能力。数据库只接受完整的无发送能力环境声明。

## 后果

- 数据库不表示微信密码、原始截图、完整聊天、成员清单或发送能力。
- 浏览器只读查看白名单、健康与投影；写入和游标由受控服务路径持有。
- 文字/HTTPS 链接手动导入已作为独立兜底落地：只接收用户主动填写的最小投影，不读取非白名单聊天或访问链接。截图安全入口仅校验白名单类型/大小、请求内临时哈希并立即删除原图；无 OCR 时只保留最小失败状态，PDF/Word/Excel 仍待后续切片。
- 微信 4.1.12.55、150% 缩放下已完成当前目标群身份/OCR、临时截图删除和纯文字 JD 端到端验证；PowerShell 5.1 到 Node 固定 UTF-8，OCR 汉字间空格在本地归一化，联系人按去空格文本识别并整行隐藏。自动截图正常路径立即删除，异常中断残留限制在专用目录并由后续启动/探测在 5 分钟内清理；删除前复核严格子目录命名与父路径。目标群变更后经用户允许重新配对，隔离 Test 保留 2 条审计行且仅当前目标群启用；真实 JD 只形成 1 条置信度 0.89 的待确认记录，未进入候选或长期表。用户级 Node LTS 与直接托管 Worker 的登录计划任务已安装并验证停止后无孤儿进程。长时间连续运行、注销/登录恢复和真实可见列表切群仍须后续验收，不能用当前结果冒充完整监测器。
- 用户已确认所有测试和正式流程永久禁止微信发送/回复/转发、联系人操作和投递；这不是可配置权限，适配器不存在相关实现入口。
- 群身份不确定、心跳过期、锁屏、UI 变化、账号风险、隐私锁或权限关闭都必须停止，覆盖状态不得显示为“无新增”。
- Worker 层对锁屏、微信退出、窗口不可用、UI 变化、账号风险、目标群不可见和同名群均有可重复的无写入失败关闭测试；本机登录任务已真实观测微信退出/登录界面不可用并连续上报覆盖中断，远端投影未增加。其余真实设备失败注入仍需用户可观察窗口验收。
