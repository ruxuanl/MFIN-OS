# ADR-0003：M3 离线写入与并发冲突

- 状态：已接受
- 日期：2026-08-10

## 背景

同一用户会在电脑与 iPhone 编辑岗位、课程和 Action。PWA 还需在短时断网时接收操作。如果只采用最后写入获胜，一端会静默覆盖另一端的新内容，违反产品对可解释冲突和追加历史的要求。

## 决策

1. PostgreSQL 是权威事实源；Realtime 只提示客户端重新读取。
2. PWA 在 IndexedDB 保存最小工作区快照和 Outbox，不缓存凭据或敏感正文。
3. 每次离线 mutation 携带全局唯一 ID、对象版本、基线字段和目标字段；服务器持久化 mutation 结果以保证幂等。
4. 服务器逐字段比较基线：服务器未改动的字段可以合并；服务器和客户端同时改动的同一字段写入显式冲突，不静默覆盖。
5. 人工解决冲突产生新的对象版本、时间线、字段锁和审计事实；原冲突值保留。
6. 岗位轨道、所有者和对象上下文属于身份字段，不参与通用合并且创建后不可变。

## 结果

- 双端不同字段编辑可以顺序收敛，同字段编辑必须由用户选择。
- 离线重试不会重复创建副作用，但客户端需保留失败和冲突状态。
- 查询和 UI 必须始终能够从服务器刷新，不能把 Realtime 消息或本地快照当成最终事实。
