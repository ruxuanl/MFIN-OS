# ADR-0006：M6 Gmail 只读适配器与统一收件箱

- 状态：Accepted
- 日期：2026-08-13
- 决策来源：用户要求按 M5 交接继续建设；D11、D18 与 M6 范围

## 背景

M6 需要从 Gmail 发现求职、学业和个人行动，但系统永久禁止发送或修改邮件。D07/D08 尚未确认，不能把规则提取冒充 AI。

## 决策

1. Gmail 独立 OAuth 只接受精确 `gmail.readonly`，令牌进入 Vault；适配器只提供 GET。
2. 首次同步限定 `in:inbox newer_than:30d` 与 50 封；后续使用 `historyId`，404 时回退同一有界查询。
3. 完整正文仅在内存中用于 `mail_rules_v1 · 非 AI` 投影；数据库不保存正文或原始 MIME。
4. 证据、最小邮件记录、收件箱项和附件元数据通过 service-only RPC 原子保存；浏览器只读。
5. 只有唯一岗位匹配、明确日期且置信度至少 0.98 的面试邀请可自动更新，并创建可取消的 Calendar 队列、通知、审计和撤销；其余进入待确认。
6. 附件默认仅保留 Gmail 链接；显式授权后复制到私有桶，支持立即删除。

## 后果

- 系统在没有 AI 的情况下仍有诚实、可测试的邮件闭环，并阻止客户端伪造同步和自动更新状态。
- 规则对复杂自然语言覆盖有限，误判路径必须留在 pending；未来 AI 版本需要新的已确认决策和策略版本。
- `gmail.readonly` 属敏感外部授权；专用测试账号已完成 OAuth、同步、暂停、远端撤销和 Vault 清理验收，当前不得进入 M7。
